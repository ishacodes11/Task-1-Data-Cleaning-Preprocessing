# Task 1 - Data Cleaning and Preprocessing

## Objective
To learn how to clean and prepare raw data for machine learning.

## Dataset
Titanic Dataset

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Steps Performed

1. Imported and explored the Titanic dataset.
2. Checked data types and missing values.
3. Handled missing numerical values using median imputation.
4. Handled missing categorical values using mode imputation.
5. Removed the `deck` column because it contained many missing values.
6. Converted categorical features into numerical features using one-hot encoding.
7. Visualized outliers using boxplots.
8. Removed outliers using the IQR method.
9. Standardized numerical features using StandardScaler.
10. Saved the cleaned dataset as `cleaned_titanic.csv`.

## Result
The raw Titanic dataset was successfully cleaned and transformed into a format suitable for machine learning.
